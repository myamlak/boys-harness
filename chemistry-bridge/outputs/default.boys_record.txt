qcx-integrals Boys kernel: what this build is

library
  version                   5.0.0                      (boys::VersionString)
  submodule revision        unknown                    (this build, captured at configure time)
  multiply-add asked for    fused                      (QCX_INTEGRALS_BOYS_MULADD_SEPARATE)
  The asked-for route is what this tree's build states, and the guards in
  qcx/integrals/boys.hpp refuse a translation unit whose definitions disagree with it.
  What the arithmetic is delivered by is a different question - a compiler flag is a
  licence rather than an instruction - and the table below is the library's own
  answer, measured where the kernels are. boys_build_record_test fails when the two
  disagree.

the seam's seven names (the fallback a class row replaces)
  boys::DefaultPolicyFp64 is boys::SeamPolicy<>: the seven names below composed
  with their own defaults. boys_build_defaults.hpp states them as the fallback a
  build that carries no row list compiles every class from. Every class this
  tree's calls reach carries a row, so no entry this build compiles runs this
  combination; it is printed because it is the seam's own identity, and because
  these are the axes a reader would otherwise take for the entries' answer.

  fit route                 chebyshev                  (boys::DefaultPolicyFp64::kRoute)
  evaluation scheme         horner                     (boys::DefaultPolicyFp64::kScheme)
  interval granularity      narrow                     (boys::DefaultPolicyFp64::kGranularity)
  packing axis              arguments                  (boys::DefaultPolicyFp64::kPack)
  engine budget             kFloat                     (boys::DefaultPolicyFp64::kBudget)
  division form             refined-reciprocal         (boys::DefaultPolicyFp64::kDivision)
  region-B exponential      fast                       (boys::DefaultPolicyFp64::kRegionBExp)
  half-lane budget          kFp16                      (boys::DefaultPolicyFp16::kBudget)
  The half-lane budget above is the one cell SeamPolicy<> carries at the half
  lane; the fp16 and bf16 class rows are the table's own and are not this name.

the region-B exponential is one of the seven cells every class row above carries;
the device entries' own default is the two-name block above. This tree names no
value for it on either surface, and a revision that moves either name moves what
the row or the block prints.

Two labels above are spelled by this file rather than read, because the library
publishes no name accessor for them: the engine budget and the row basis. Every
value beside them is the library's.
