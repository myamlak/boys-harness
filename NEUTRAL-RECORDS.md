# Neutral records

This harness is a code and data deposit, not a publication. The campaign
studies cite the neutral copies listed here. A copy exists because the original
record carries a historical internal name; the data and digests are identical,
and the copy is the citation target. Each tree's `neutral/` directory mirrors
the relative path of every labelled original below the tree root.
